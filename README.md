# 🏋️ Gym → FitLife'a Taşındı

Bu repodaki antrenman takibi uygulaması, **[Eat](https://github.com/TamerlanBakirov/Eat)** reposundaki beslenme uygulamasıyla birleştirilerek **FitLife** adlı kapsamlı bir mobil uygulamaya dönüştürüldü.

## Yeni adres

Geliştirme artık **[TamerlanBakirov/Eat](https://github.com/TamerlanBakirov/Eat)** reposunda sürüyor (bkz. `claude/app-consolidation-5riiyk` dalı ve [PR #1](https://github.com/TamerlanBakirov/Eat/pull/1)).

## FitLife'ta Gym'den gelenler

- 🏋️ **Antrenman sekmesi:** 40+ egzersizlik kütüphane (göğüs, sırt, bacak, omuz, kol, karın, kardiyo)
- 📋 Set / tekrar / ağırlık bazlı kuvvet kaydı ve süre bazlı kardiyo kaydı
- 🗂 5 hazır program şablonu: Tüm Vücut, Push, Pull, Legs, Kardiyo
- 🔥 MET değerine göre otomatik kalori yakımı tahmini
- 🏆 Kişisel rekor takibi

## Birleşmenin getirdikleri

Antrenman verileri artık beslenme günlüğüyle aynı uygulamada yaşadığı için:

- **Net kalori dengesi:** alınan − yakılan kalori tek ekranda
- Antrenman yakımı, günlük kalori hedefine otomatik yansır
- Tek profil üzerinden ortak hedef (kilo verme / koruma / kas alma) yönetimi

Teknoloji: React Native (Expo SDK 53), React Navigation, AsyncStorage, react-native-svg.
